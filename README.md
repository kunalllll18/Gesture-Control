# Gesture Control System 🖐️

A real-time hand gesture recognition system built using Python, OpenCV, and MediaPipe to control mouse movements and perform clicks using hand gestures.

## 🚀 Features
- Real-time hand tracking using a webcam
- Mouse cursor movement using hand gestures
- Gesture-based clicking
- Smooth cursor control

## 🛠️ Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## ⚙️ Installation

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:
   ```bash
   cd gesture-control
   ```

3. Install dependencies:
   ```bash
   pip install opencv-python mediapipe pyautogui
   ```

4. Run the Python script:
   ```bash
   python main.py
   ```

   Replace `main.py` with your actual Python filename if different.
